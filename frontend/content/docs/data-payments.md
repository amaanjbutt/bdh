# Digital payments

Bangladesh Bank's e-Banking and e-Commerce Statistics unit publishes monthly workbooks for:

- Mobile Financial Services (MFS): accounts, agents, merchants, cash-in/cash-out, P2P, merchant payments, government-to-person and more
- Cards: issued cards by gender/currency/type, ATM/POS/CRM transactions
- Internet banking: customers, app users, transaction counts and values
- QR code transactions
- School banking and special accounts
- Agent banking: agents, outlets, deposits, loans and transactions

Values are counts or BDT million. The series ids follow the publisher's table and column
names, e.g. `payments.mfs_part_3.cash_in_total_amount`.
